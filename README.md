## 💰 Smart Expense Tracker with Data Visualization

A simple Python application that helps users record, manage, and visualize their personal expenses across categories such as Travel, Food, Entertainment, and more.

---

### ✨ Features

✅ **Add Expenses** – Add new expenses under predefined or custom categories. <br>
✅ **View Expenses** – See a summary of all expenses entered so far. <br>
✅ **Filter Expenses** – Focus on spending in a specific category. <br>
✅ **Edit Expenses** – Update amounts for any expense category. <br>
✅ **Remove Expenses** – Delete any expense category completely. <br>
✅ **Visualize Data** – Generate bar charts or pie charts to see spending distribution. <br>
✅ **Data Persistence** – Expenses are saved to a text file (`expenses.txt`) to retain data between sessions.

---

### 🛠️ Technologies Used

* **Python**
* **NumPy**
* **Pandas**
* **Matplotlib**

---

### 📊 Demo

When you run the app, you’ll see a text-based menu like:

```
1. Add new expense
2. View all expenses
3. Filter expenses by category
4. Edit expense
5. Remove expense
6. Visualize expenses
7. Quit
```

Choose an option to add expenses or generate charts!

---

### 📂 Data Storage

* Expenses are stored in a simple text file: `expenses.txt`.
* On starting the application, it automatically loads your previous data so you can continue where you left off.
